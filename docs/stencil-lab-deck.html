Part 1

The kernel

Level 0 · naive

One update, eight flops

Each interior point becomes a weighted sum of itself and its six face neighbours. Two buffers, swapped every step; a one-cell halo holds the boundary.

  • x innermost: neighbours in i share cache lines
  • 8 FLOPs per point: 6 adds, 2 muls
  • 24 B per point: read, write, write-allocate
  • ≈ 0.33 FLOP/byte: bandwidth-bound

Tests

Correct before fast

  • A constant field stays constant, boundary included
  • A sine mode decays by exactly λᵀ, the discrete eigenvalue
  • Tests run on 30×40×50, so a swapped stride can't hide behind a cube's symmetry
Checked

A build with a deliberately wrong stride failed the sine-mode test. The test catches the bug it was written for.

Note

Every later level must match Level 0's checksum. A fast wrong answer is worth nothing.
